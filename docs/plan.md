## Что готово

Бот работает с настоящим токеном на Mac. Логика покрыта тестами без сети (`pytest`), сквозной путь новичка проверяет отдельный тест.

- Новичка заводит HR в кабинете, он получает личную ссылку и QR, открывает её в МАКС и выбирает «ты» или «вы». Ссылка одноразовая.
- Сценарий из 117 шагов: время по часовому поясу новичка, перенос с выходных и праздников, теги площадок, ветки по кнопкам, опросы и шкала с вопросом «что не так?», напоминания.
- Ответы на вопросы по документам со ссылкой «документ, пункт». Защита от выдумок: порог близости, `NO_ANSWER`, проверка чисел, второй вызов модели, стоп-темы.
- Упрощённый режим, когда модель недоступна, с подписью и уведомлением HR.
- Эскалация рекрутеру с пятью последними сообщениями, ответ возвращается новичку, пара «вопрос-ответ» добавляется в базу знаний.
- Пульс настроения, красные флаги рекрутеру сразу, сводка после опроса, команда `/сводка`, выгрузка Excel из четырёх листов.
- Кабинет HR (голый HTML): новички, рекрутеры, база знаний, вопросы, сценарий.
- Демо-режим: `/next` или кнопка в карточке перематывает время.
- Набор для компьютера с Windows: установка Ollama, правила брандмауэра, окно «Корсик модель» с кнопкой «Включить» / «Выключить». Скрипты написаны, на самом компьютере ещё не запускали.
- Docker (`Dockerfile`, `compose.yaml`), инструкция по серверу, описание устройства для экспертов.

## Сценарий видео

1. HR в кабинете заводит рекрутера и новичка, показывает ссылку и QR.
2. Новичок открывает ссылку в МАКС, выбирает «ты» или «вы», приходят первые шаги.
3. `/next` до первого опроса: новичок ставит низкую оценку, бот спрашивает «что не так?», рекрутер получает сводку.
4. Вопрос «во сколько начинается рабочий день»: ответ с источником «ПВТР, п. 6.6.1».
5. Вопрос, которого нет в документах: рекрутер получает его с контекстом, отвечает, ответ приходит новичку.
6. Красный флаг: новичок пишет, что хочет уйти, рекрутер получает уведомление.
7. Выключаем модель в окне Windows, показываем упрощённый режим.
8. Excel-выгрузка и карточка новичка в кабинете.

## Риски

- Домен. Если DNS сменится поздно, сертификат не выпустится вовремя. Тогда показываем кабинет по `http://127.0.0.1:8080` на ноутбуке.
- Модель. Компьютер с Windows может уснуть или потерять Tailscale. Чтобы он не засыпал, установку запускают с флагом `-NoSleep`; перед защитой всё равно проверить.
- Картинки и факты HR могут не прийти. Бот работает без них, но шаги с пометками `[HR: ...]` выглядят суше.
- Кабинет станет виден из интернета. Нужен длинный `ADMIN_PASSWORD`; других ограничений, кроме паузы в секунду после неверного пароля, там нет.
