# data/

Рабочая папка бота. Всё, что в ней лежит, кроме этого файла, создаётся при работе и в git не попадает.

- `korsik.db` - база SQLite: новички, переписка, ответы на опросы, вопросы к HR, документы и их векторы. Создаётся при первом запуске. WAL-файлы рядом (`-wal`, `-shm`) трогать не нужно.
- `kb/` - исходные файлы документов компании. Нужны, чтобы перезагрузить базу знаний (`python -m tools.load_kb data/kb/файл`).
- `uploads/` - файлы, которые HR загрузил через кабинет, под случайными именами.
- `images/` - картинки к шагам сценария, имена как в колонке «Картинка». Если файла нет, шаг уходит текстом.
- `scenario-previous.xlsx` - прошлый сценарий, кабинет кладёт его сюда перед заменой.

Файлы компании и база содержат данные людей. Не отправляйте их в чужие сервисы и не коммитьте. Копия базы для хранения делается способом из `docs/deploy.md`, а не копированием `korsik.db` под работающим ботом.
