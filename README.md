# Корсик 2.0

Бот в мессенджере МАКС: ведёт нового сотрудника Группы ПОЛИПЛАСТИК от оффера до конца испытательного срока, отвечает на вопросы по документам компании и передаёт рекрутеру то, чего в документах нет. Языковая модель работает в контуре компании, вопросы и документы в облако не уходят.

Хакатон «Открой#Моспром», кейс «ИИ-ассистент в МАКС для адаптации персонала», команда УДАВ.

## Посмотреть

- Бот в МАКС: «Корсик Помощник», `@id500404830995_bot`. Попасть в него можно только по личной ссылке, которую выдаёт HR в кабинете.
- Кабинет HR: https://korsik.udav.team (вход по паролю, выдаём экспертам по запросу).
- Мини-приложение в МАКС: https://korsik.udav.team/app, вход по подписи МАКС.
- Видео-демо, презентация и тизер: ссылки в личном кабинете хакатона.

## Что умеет

- Сценарий адаптации из 117 шагов в Excel: время по часовому поясу новичка, перенос с выходных и праздников, теги площадок, ветки по кнопкам, опросы со шкалой и вопросом «что не так?». HR правит файл сам, бот проверяет его перед заменой.
- Ответы на свободные вопросы по документам (RAG): поиск по словам и по смыслу, ответ только по найденным пунктам. Защита от выдумок сделана кодом: порог близости, проверка каждого числа, телефона и почты по тексту пункта, второй вызов модели для ответов с цифрами. Не прошла хоть одна проверка, вопрос уходит рекрутеру.
- Передача рекрутеру с пятью последними сообщениями, ответ приходит новичку в рабочее время его площадки, пара «вопрос-ответ» одной кнопкой попадает в базу знаний.
- Пульс настроения и красные флаги, риск ухода от 0 до 100, «Как ты?» раз в неделю, тёплая реакция на слова об уходе и сразу человек.
- Задачи новичка с напоминаниями, руководитель с памятками к встречам, короткие уроки по ПВТР и коммерческой тайне.
- Кабинет HR: новички, места работы, рекрутеры и руководители, база знаний с блоком «Чего не хватает в базе», вопросы, дашборд, выгрузка Excel.
- Упрощённый режим, если модель выключена: бот не падает и честно об этом пишет.

Подробно и простым языком: [docs/how-it-works.md](docs/how-it-works.md).

## Из чего сделано

Python 3.12, один процесс: FastAPI и uvicorn для кабинета, рядом циклы asyncio (приём событий МАКС и планировщик сценария). SQLite с FTS5 для поиска по словам, векторы считает numpy. Документы разбирают pymupdf, python-docx, python-pptx и tesseract. Сценарий и отчёты в Excel через openpyxl.

Модели в боте открытые и работают локально через Ollama:
- `qwen3:14b` (запасная `qwen3:8b`), лицензия Apache 2.0: ответы по найденным пунктам, проверка ответов, разметка настроения;
- `bge-m3`, лицензия MIT: векторы для поиска по смыслу.

Весь код работы с моделями лежит в репозитории: `app/llm.py` (клиент Ollama), `app/qa.py` (ответы и проверки), `app/knowledge.py` (поиск).

## Запуск

Нужны Python 3.12 и токен бота из кабинета МАКС. Для сканов PDF ещё tesseract с русским языком, для умных ответов Ollama с моделями `qwen3:8b` (или `qwen3:14b`) и `bge-m3`. Без Ollama бот всё равно стартует и отвечает цитатами из документов.

```
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python -m app.main
```

В `.env` вписать `MAX_BOT_TOKEN`, `ADMIN_PASSWORD` и `SECRET_KEY` (любая длинная случайная строка). Если модель стоит на другом компьютере, там же `OLLAMA_URL` и `LLM_MODEL`.

Кабинет HR открывается на http://127.0.0.1:8080. Сначала добавьте рекрутера и дайте ему открыть свою ссылку в МАКС, потом заведите новичка и отправьте ему ссылку или QR. В демо-режиме (`DEMO_MODE=1`) команда `/next` перематывает время новичка к следующему шагу.

Документ в базу знаний можно загрузить в кабинете или командой `.venv/bin/python -m tools.load_kb PATH --tags "GrPP"`.

На сервере бот запускается в Docker: `docker compose up -d --build`. Порт кабинета открыт только на 127.0.0.1, снаружи его отдаёт прокси. Подробности в [docs/deploy.md](docs/deploy.md), компьютер с моделью в [deploy/windows/README.md](deploy/windows/README.md).

## Проверка

`.venv/bin/python -m pytest -q`: 311 тестов, в сеть не ходят. Сквозная проверка на сервере (отдельный контейнер из рабочего образа, копия базы, заглушка вместо МАКС, настоящая модель) прошла 117 из 117.

## Где что лежит

| Папка | Что там |
|---|---|
| `app/` | бот, планировщик, ответы по документам, кабинет и мини-приложение |
| `scenario/` | сценарий `scenario.xlsx`, праздники, уроки обучения, позы Корсика |
| `kb-demo/` | демо-справки по питанию на площадках с пометкой «ДЕМО» |
| `tools/` | загрузка документов, распознавание сканов, сборка сценария |
| `deploy/windows/` | установка модели на компьютер с Windows и окно «Корсик модель» |
| `tests/` | автотесты |
| `docs/` | как устроено, выкладка, эффект и аналоги, план |

Документы компании и база в `data/` в репозиторий не входят.
